ML Mantiqi: Optimizatsiya

Model ma'lumotlarga qanday moslashadi:

  • Kiruvchi ma'lumotlar: Ko'k nuqtalar (tarixiy faktlar).
  • Model (Chiziq): Binafsha chiziq tendensiyani bashorat qilishga urinadi.
  • Xatolik: Chiziq nuqtalardan qanchalik uzoqligini o'lchaydi.
  • O'rganish: U xatoni kamaytirish uchun avtomatik ravishda o'zini to'g'rilaydi.

"Gradient tushish" (Gradient Descent) algoritmini ko'rish uchun "Qayta o'rnatish" tugmasini bosing.

Bugungi Birinchi G'alabangiz

Zamonaviy kutubxonalar murakkab matematikani yashiradi. AIni o'qitish atigi 3 qator kodni oladi.


# 1. Miyani Tanlash (Modelni yaratish)
from sklearn.linear_model import LinearRegression
model = LinearRegression()

# 2. Miyani O'qitish (Tarixiy ma'lumotlar va to'g'ri javoblardan o'rganish)
model.fit(tarixiy_malumotlar, togri_javoblar)

# 3. Kelajakni Bashorat Qilish (Unga yangi savol bering!)
kelajak_bashorati = model.predict(yangi_korilmagan_malumotlar)
